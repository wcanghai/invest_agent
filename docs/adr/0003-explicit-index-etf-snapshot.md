# ADR 0003: 使用显式标的快照驱动指数与 ETF 归档

## Status

Accepted

## Context

指数成分和 ETF 流动性会变化。若每次日线同步都动态发现标的，数据库研究范围会在没有审计记录的情况下漂移；手工维护数百代码又容易遗漏。

## Decision

- 用通达信集合 23、24生成当前沪深300和中证500快照。
- 用通达信集合 31 的近 60 日日均成交额选择前 120 只 ETF。
- 生成显式 JSON 配置，日线同步只读取该快照。
- SQLite 行情数据库不进入版本控制；公开代码配置可以版本化。

## Consequences

- 研究样本可复现，并能知道生成时点与选择规则。
- 成分更新需要显式重建配置和审查差异。
- 当前成分的历史行情不代表历史成分，使用者必须意识到幸存者偏差。
