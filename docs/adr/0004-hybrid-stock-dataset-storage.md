# ADR 0004: 股票全维度数据采用固定表与 JSON 混合存储

## Status

Accepted

## Context

通达信股票接口同时返回稳定的日线/公司行为/股本数据，以及字段众多、版本可能变化的当前快照。单一宽表难以维护，纯 EAV 又会损害记录完整性和读取效率。

## Decision

日线、公司行为、股本、财务事实和板块关系使用固定或长表；基础资料、行情快照、扩展指标和编号式专业数据以规范化 JSON 记录保存，并同步维护字段目录。

## Consequences

- 核心历史数据可直接 SQL 查询并设置自然唯一键。
- 动态接口能够完整保存未知字段而无需迁移。
- 跨股票比较动态字段时需要 SQLite JSON 函数或后续物化因子表。
