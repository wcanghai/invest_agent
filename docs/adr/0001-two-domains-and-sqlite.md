# ADR 0001：双业务域与 SQLite 持久化

状态：已接受。

## 决策

代码只按“日报”和“TDX 完整归档”划分两个业务包。日报用一个 SQLite 管理标的、历史行情、新闻、报告和同步审计；TDX 使用独立 SQLite。删除 CSV 缓存、统一转发 CLI 和旧包兼容层。

## 原因

SQLite 提供唯一约束、事务、范围查询和服务重启后的持久性，适合本地单机工作流；分离 TDX 大库可减少锁竞争和职责耦合。直接保留各功能命令比再增加一个无业务价值的总入口更清晰。

## 影响

用户需要改用新模块路径；控制台命令名称保持不变。生成数据库不得进入 Git，备份和迁移由本地数据管理负责。
