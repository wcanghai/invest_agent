# ADR 0002: 运行时发现通达信全市场标的并显式启用全量同步

## Status

Accepted.

## Context

A 股和 ETF 上市/退市会持续变化。将数千个代码固化在仓库配置中易过期，而默认运行全量十年采集的时间和磁盘代价又过高。

## Decision

- 使用通达信集合 `5` 和 `31` 在每次运行时发现所有 A 股与 ETF。
- 命令默认每类限制 5 个标的，作为安全冒烟模式。
- 只有显式 `--all` 才取消上限。
- 日线仍逐只读取并单只事务提交，通过数据库最新日期恢复中断任务。

## Consequences

- 证券范围随本地通达信客户端保持更新，无需提交庞大代码列表。
- 日常误运行只会处理少量标的；操作者必须明确选择全量任务。
- 全量任务仍是长时间单进程作业，但可安全重运和续传。
