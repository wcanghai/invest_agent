# ADR 0002：按报告期和公告日保存 TDX 财务历史

## 状态

已接受。

## 决策

财务历史使用 `(code, report_date, announce_date)` 作为业务键，并保留完整原始 payload；所有返回字段另存到 EAV 明细表。历史指标只允许连接到交易日当时已经公告的数据；PB 必须由调用方显式指定已经验证的每股净资产字段。

## 原因

报告期说明数据归属期间，公告日决定市场何时能获知该数据。只按报告期连接会产生未来函数；只按采集日保存又无法恢复历史可知状态。

## 后果

- 可以构建无未来函数的 point-in-time 数据集。
- 更正公告可用新的公告日保留为新版本。
- 新增 Fn 字段不要求修改数据库结构，旧 JSON 记录可自动回填字段明细。
- 指标计算仍依赖可靠的字段字典；当前 Fn193-Fn200 需要进一步校验。
