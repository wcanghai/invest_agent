# ADR 0003：物化 point-in-time 日频量化宽表

## 状态

Accepted

## 决策

在 TDX SQLite 归档库中新增 `quant_daily_wide` 物化表。财报按公告日、股本按生效日、快照按精确观察日连接；不把当前指数成员关系回填到历史，也不在基础宽表中保存未来收益标签。

## 原因

量化研究会反复读取相同的日线、财务、股本和事件连接结果。物化表增加存储成本，但能提供稳定、可审计且快速的横截面输入。严格的可知时间规则比用“最新值”回填更重要。

## 后果

- 每日归档后需要运行宽表增量构建。
- 数据库体积增加。
- 研究者仍需单独构造预测标签和训练/验证切分。
- 新的事件数据源未来可通过加列或独立特征表扩展。
