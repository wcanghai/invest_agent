# 文档导航

## 使用说明

- `guides/tdx-history.md`：A 股与 ETF 十年日线增量采集。
- `guides/tdx-stock-data.md`：十只股票全维度通达信试采集与 SQLite 查询。

## 生命周期文档

- `requirements/`：需求范围和验收标准。
- `design/`：架构、数据模型和接口设计。
- `adr/`：关键技术决策记录。
- `tasks/`：实施任务和验证命令。
- `release/`：发布、回滚和剩余风险。

同一功能应在上述目录使用一致文件名，例如 `repository-organization.md`，便于从需求追踪到发布。
