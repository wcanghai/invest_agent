# 实施任务：TDX 每日增量

## 范围

1. 扩展 SQLite 历史表和幂等写入函数。
2. 扩展 TdxClient 的历史财务、股本、公司行为和动态快照接口。
3. 将附加数据纳入 `archive_stocks`，统一快照日期并支持重叠增量。
4. 新增从数据库标的运行的 `tdx-daily-update` 命令。
5. 补充离线测试、中文使用说明和可行性分析。
6. 增加财务字段明细、结构化公司行为和 point-in-time 历史指标输入服务。

## 非目标

- 不创建 Windows 计划任务。
- 不执行全市场真实采集。
- 不计算未经字段校验的历史财务指标。

## 验收与验证

- `python -m pytest -q -p no:cacheprovider`
- `git diff --check`
- 检查重复执行后的表行数、增量请求起点及统一快照日期。
- 检查历史交易日只连接当时已公告财报，且旧报告期更正不覆盖更新报告期。

## 回滚

新增表可由旧代码忽略；不删除、不改写现有表中的历史数据。代码回滚不会影响既有归档读取。
