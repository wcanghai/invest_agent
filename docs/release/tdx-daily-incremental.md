# 发布：TDX 每日增量与历史财务归档

## 变更摘要

- `tdx-full-archive` 默认同步历史财务、历史股本、公司行为和每日动态快照。
- 新增 `tdx-daily-update`，从数据库读取已归档标的并执行每日增量。
- 新增财报双时间轴、股本、公司行为和标的集合历史表。
- 新增通用财务字段明细表和 point-in-time 历史指标输入服务。
- 公司行为的分红、送股、配股和配股价可直接查询。
- 修复长任务跨午夜造成同一次运行快照日期不一致的问题。
- ETF 跳过不适用的公司财报接口；每日命令支持 `--start-after` 断点续跑。

## 使用者影响

首次启用扩展归档会回溯历史，耗时和数据库增长明显；后续运行只请求增量窗口。可用 `--skip-extended-data` 临时保持原有轻量行为。

## 数据库与配置

打开旧数据库时只执行 `CREATE TABLE/INDEX IF NOT EXISTS`，不删除或改写旧表。无需新增凭证或环境变量。

## 发布步骤

1. 安装更新后的项目：`python -m pip install -e ".[dev]"`。
2. 先用 `tdx-daily-update --limit 1` 验证本机 TQ 和数据库迁移。
3. 执行一次全量扩展历史回填。
4. 配置收盘后调用 `tdx-daily-update` 的计划任务。

## 监控

- 检查 `sync_runs.status`、`failed_codes` 和命令退出码。
- 观察 `financial_reports`、`share_capital_history` 的最大业务日期。
- 关注数据库磁盘增长和 TQ 的 `server no return` 日志。

## 回滚

可回退代码并继续读取原有日线和快照表；新增表由旧代码忽略。不要删除新增表，因为其中可能已经包含无法轻易重新下载的历史记录。
